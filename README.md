# 🌌 Cyber-Violet Audio Visualizer

Эстетичный аудио-визуализатор для браузера, вдохновленный атмосферой ночного города и японскими Lo-fi битами. Проект создан для глубокого погружения в музыку с акцентом на плавность, симметрию и неоновую фиолетовую палитру.

## ✨ Особенности
* **Smooth Flow:** Использование инерционного сглаживания звуковых частот для устранения резких скачков.
* **Symmetry Mirror:** Идеальное зеркальное отражение спектра (басы центрированы).
* **Neon Atmosphere:** Градиентная заливка с эффектом свечения (Glow) и шлейфом (Motion Blur).
* **System Audio Capture:** Возможность захвата звука напрямую из любой вкладки браузера (YouTube, Spotify и др.).

## 🚀 Как запустить

1.  **Склонируйте репозиторий:**
    ```bash
    git clone https://github.com/nettaisdead/visualizer.git
    ```
2.  **Откройте проект:**
    Используйте расширение **Live Server** в VS Code (или любой другой локальный сервер), чтобы открыть `index.html`. 
    *Примечание: Прямое открытие файла через двойной клик может заблокировать доступ к аудио из-за политики безопасности браузера.*

3.  **Активация:**
    * Нажмите кнопку **"ACTIVATE NIGHT MODE"**.
    * В появившемся окне выберите вкладку с музыкой.
    * **Важно:** Обязательно поставьте галочку **"Общий доступ к аудио системы"** в нижнем углу окна выбора.

## 📱 Использование на телефоне
Проект оптимизирован для работы в качестве живых обоев через приложение **Wallpaper Engine** (Android) или через **GitHub Pages**.

Для лучшего отображения на мобильных устройствах рекомендуется изменить коэффициент высоты `h` в файле `draw.js` на более высокий.

## 🛠 Технологии
* **HTML5 Canvas API** — для отрисовки графики.
* **Web Audio API** — для анализа частот в реальном времени.
* **JavaScript (ES6+)**.

## 🎨 Настройка стилей
Все основные параметры визуализации находятся в функции `animate()` файла `draw.js`:
* `smoothingFactor`: отвечает за плавность (чем меньше, тем "медленнее" волны).
* `hsla(280, ...)`: меняет цвет (280 — это фиолетовый, 200 — голубой, 0 — красный).
